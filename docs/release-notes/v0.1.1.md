plethron is a PC port of **Pocket Monsters Stadium** (N64, Japan, 1998), built on the team-hippodrome decompilation
and libultraship. It is preservation work: the game plays as it did on the N64, and everything new is an option, off
unless you turn it on.

**No game data is included.** You need your own dump of the original Japanese ROM (`.z64`); Game Boy carts for the
GB Player and Transfer Pak are your own dumps too.

## New since v0.1.0

- **macOS build** (Apple Silicon): the port's lifted game data is now linked with Apple's linker too, so the release
  has a macOS app. It is checked by CI (the linked addresses and a start of the executable) but has not yet been played
  with a ROM on a real Mac, so please report anything that goes wrong.
- **More optional enhancements** (launcher > Graphics > Enhancements, all off by default):
  - Hue choice: on the entry screen where you pick your Pokémon for a cup, L / R change the colour of a Pokémon's
    model on its card and Z resets it; Z on a party row or a rental opens a colour card. Kept in `<save>.hue` beside
    the N64 save, and kept when a tournament is resumed.
  - Move descriptions: in the fight menu, hold a D-pad direction to see the type, power, accuracy and description of
    the move on that direction's C button (the C buttons still pick the move).
  - Order queueing (battles against the COM only): press Z while a turn plays out to pick your next order; it is
    entered as soon as the next command menu opens, as fast as mashing would be.
  - Summary bars now also show on the order screen while the trainers pick their Pokémon: your side with its moves
    and exact Speed, the opponent's as trainer memory remembers it.
- **Cheats** (launcher > Cheats, shown with Debug on; all off by default, and the button turns amber while one is
  set): battle cheats per player (Infinite HP, Infinite PP, never miss, always first, perfect stats and more), which
  change only the running battle and never the N64 save, and GameShark codes for the Game Boy games in the Transfer
  Paks.
- **Language select** opens and closes like the game's own windows, appears only on the first launch, and is
  followed by a note that the language can be changed in Options. Options has a new Language row.
- **Small text:** translated text smaller than 16 px is drawn bold without the outline by default, like the game's
  own small font sets (launcher > Graphics > Small text picks outline, plain or bold).
- **Switch menu:** in translated languages, fainted and statused Pokémon are marked with status symbols instead of the
  Japanese kana stamps. にほんご and Japanese with kanji keep the original stamps.
- **Widescreen:** the menus' top header bar (1P, name, ID No. and screen title) now reaches the 16:9 edges, and the
  sides no longer flicker black the first time the main menu opens.
- **Tournament resume:** a resumed team of rentals shows Zero's default name 1P again instead of a blank name.
- **Windows:** fixed a build break in the cheats code (Windows only).

## Builds

- Windows x64 and arm64 (zip: `plethron.exe`)
- Linux x86_64 AppImage (`chmod +x` after downloading)
- macOS arm64 (zip: `Plethron.app`)

## Known differences

- Sleep Powder and Haze look different from the N64 (the accurate colour combiner looked worse, so it was kept).
- When a Pokémon faints, no cry plays. This is how Zero does it on the N64 too.
